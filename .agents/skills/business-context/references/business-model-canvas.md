# Business Model Canvas Reference

Use BMC components only when they can change the current Opportunity or Viability decision. Complete all nine only for a consumer that needs a full business-model view.

| Component | Decision it can inform |
|-----------|------------------------|
| Customer Segments | Who receives value and whose behavior differs |
| Value Propositions | Which job, pain, or gain the product addresses |
| Channels | How customers discover, obtain, or receive the value |
| Customer Relationships | What acquisition, service, or retention model is required |
| Revenue Streams | How and when value produces revenue |
| Key Resources | Assets required to deliver the proposition |
| Key Activities | Capabilities required to deliver it |
| Key Partnerships | External dependencies and ownership |
| Cost Structure | Costs that can change viability or scope |

For each included component, cite the evidence and state the Opportunity, risk, or scope decision it affects. Record unsupported claims as assumptions.
