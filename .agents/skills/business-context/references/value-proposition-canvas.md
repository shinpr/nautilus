# Value Proposition Canvas Reference

Use the smallest Customer Profile and Value Map needed to assess Problem-Solution Fit for the current Opportunity.

## Customer Profile

- **Jobs**: evidenced functional, social, or emotional outcomes
- **Pains**: obstacles or undesired outcomes that affect priority
- **Gains**: required or desired outcomes that affect value

## Value Map

- **Products and services**: current solution candidates
- **Pain relievers**: candidate-to-pain mappings supported by evidence
- **Gain creators**: candidate-to-gain mappings supported by evidence

Assess fit by tracing each retained solution element to an evidenced job, pain, or gain. Rank items only when competing candidates require comparison. Treat unsupported mappings as hypotheses rather than filling the canvas.

Use jobs and pains to frame Opportunities, and use reliever or creator claims as Value or Usability hypotheses when they still require validation.
